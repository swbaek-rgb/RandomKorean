# 한반도 생애 시뮬레이터

4만 년 전부터 2026년까지, 한반도에서 태어난 어떤 한 사람의 삶을 시대별 통계로 무작위 생성하는 정적 웹사이트.

**사이트:** https://swbaek-rgb.github.io/RandomKorean/ — `main` 에 푸시하면 GitHub Actions 가 자동으로 빌드·배포한다 (`.github/workflows/deploy.yml`).

```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 정적 빌드 (타입 검사 포함)
```

## 화면 흐름

1. **시작** — 제목, 시대 균등/출생아 가중 토글, '생년 정하기' 버튼. 아래 '생년 직접 입력하기'를 누르면 열 개 시대가 같은 폭으로 놓인 연표가 열리고, 손잡이를 끌거나(화살표 ±1년, Shift ±10년, PageUp/Down ±100년) 연도를 직접 쳐서 생년을 고른 뒤 바로 상세 화면으로 간다
2. **생년 공개** — 숫자가 무작위로 돌다가 느려지며 생년에 멈춤. '다음' 또는 '다시 뽑기'
3. **상세** — 생년과 시대에 따른 이름·거주·계급·가족·직업·주식·사망 카드

## 동작 방식

'생년 정하기'를 누르면 시드가 하나 생기고, 그 시드로 아래 순서대로 항목을 뽑는다. 뒤 항목은 앞 항목에 의존한다.

1. **생년** — 기본은 *시대 균등*(열 개 시대 중 하나를 같은 확률로 고른 뒤 그 안에서 연도 추첨). 토글로 *출생아 가중*(연도별 추정 인구 × 출생률에 비례) 선택 가능.
2. **성별** — 출생 성비 105:100
3. **거주 국가·지역** — 시대별 국가와 지역 인구 비중
4. **계급** — 골품제, 고려 신분제, 조선 양반·중인·상민·노비(연도별 비율 변동), 일제강점기 농가 계층, 현대 남한 소득분위·북한 성분
5. **가족** — 합계출산율로 형제 수. 혼인은 혼인 시점 연도의 평균 초혼연령(통계청 혼인통계)에 ±3년 편차, 평생 미혼 여부는 45세 시점 생애미혼율(인구총조사), 이혼은 조이혼율을 부부당 연간 위험으로 환산해 매년 판정, 사별은 배우자 생존을 같은 생명표로 시뮬레이션, 재혼은 시대·성별·계급별 확률(조선 양반 여성 재가 금지 등). 자녀 수와 생존 자녀 수는 혼인 기간과 합계출산율로 결정
6. **이름** — 계급·성별·시대에 따라 고유어 이름, 성 없는 이름, 항렬자 한자 이름, 세대별 인기 이름
7. **직업** — 계급과 시대 산업 구조
8. **사망** — 매년 연령별 사망확률(Makeham 모형)을 굴려 사망 여부 판정. 전쟁·기근·역병 사건은 해당 연도에 추가 위험으로 얹음. 2026년까지 살아남으면 현재 나이 표시.
9. **주식** — 시대·지역·계급별 식생활

같은 시드는 항상 같은 삶을 만든다. URL의 `?s=시드&m=w` 로 공유할 수 있고, 직접 고른 생년은 `?s=시드&y=연도` 로 공유된다 (기원전은 음수).

## 디자인·모션

- **아트 디렉션** — "먹빛 어둠 속에서 떠오르는 한 사람의 생". 먹(#0b0a09) 바탕에 한지색 글자, 시대마다 다른 빛깔(돌·흙·청동·황토·금·청자·쪽·자주·재·백자)의 광원 하나가 느리게 숨쉰다. 생년이 드러나는 순간 광원이 그 시대의 색으로 바뀐다.
- **서체** — Nanum Myeongjo (제목·서사·숫자), Pretendard (UI). 둘 다 OFL.
- **모션 스택** — GSAP(진입 안무, 단어·문장·행 stagger), Lenis(상세 화면의 유일한 스무스 스크롤 엔진, ScrollTrigger에 연결). `prefers-reduced-motion`이면 안무와 스무스 스크롤을 모두 끄고 최종 상태를 즉시 그린다.
- **Three.js** — 쓰지 않음. 타이포그래피 중심 컨셉이라 셰이더 캔버스가 정당화되지 않는다.
- **아이콘** — Solar (Iconify, CC BY 4.0) 오프라인 번들.
- **이미지·아바타·로고** — 없음. 사진 자산 없이 활자와 데이터 그래픽(시대 띠)만 쓴다.

브라우저 검증: `npm run shots` 가 시스템 Chrome을 Playwright로 띄워 데스크톱·모바일·감소 모션 세 조건에서 화면을 `shots/` 에 캡처한다.

## 지역 세분화 (당시 지명 + 지금의 대표 지역)

거주 지역은 `src/data/regions/*.json` 스냅숏에서 뽑는다. 스냅숏은 특정 시점의 행정구역 목록과 호구·인구·출생아 가중치이며, 옛 경계를 현재 경계로 쪼개지 않고 **당시 지명 그대로 표시하고 괄호에 지금의 대표 지역 한 줄**을 붙인다. 예: `경상도 동래부 (지금의 부산)`.

| 스냅숏 | 적용 출생 연도 | 가중치 | 원본 | 상태 |
|---|---|---|---|---|
| 1789 호구총수 | 1392~1896 | 구 | 규장각 奎 1602. 군현별 호·구 | 비어 있음 (CSV 필요) |
| 1935 국세조사 | 1897~1944 | 인구 | KOSIS `DT_1IN3501`. 부·군별, 남북 전역 237곳 | 채움 |
| 1955 인구총조사 (남한) | 1945~1964 | 인구 | KOSIS `DT_1IN5501`. 시·군 173곳 | 채움 |
| 1975 인구총조사 (남한) | 1965~1982 | 인구 | KOSIS `DT_1IN7501` (당시 행정구역) | 채움 |
| 1990 인구총조사 (남한) | 1983~1994 | 인구 | KOSIS `DT_1TS2003` 시계열 | 채움 |
| 2020 출생아 수 (남한) | 1995~2026 | 출생아 | KOSIS `DT_1B81A01` 시·군·구 229곳 | 채움 |
| 2008 인구센서스 (북한) | 1945~2026 | 인구 | 중앙통계국·UNFPA 시·군 | 비어 있음 (CSV 필요) |

호구 비율이 없는 고려 이전은 세분화하지 않고 도·주 단위 추정에 머문다. 스냅숏 파일의 `rows` 가 비어 있으면 해당 시대는 자동으로 도 단위로 폴백한다.

**수치 채우기.** 기억으로 적은 군현 수치는 신뢰할 수 없으므로 전부 원본에서 가져온다. KOSIS 표는 스크립트로 받고, `scripts/annotate-now.mjs` 가 옛 지명에 "지금의 대표 지역"을 붙인다 (대응표 `scripts/maps/now-map.json`, 없으면 접미사 제거·북한 지역은 "북한 ○○").

```bash
# KOSIS 오픈 API (https://kosis.kr/openapi 에서 키 발급)
KOSIS_API_KEY=... node scripts/import-kosis.mjs DT_1B81A01 2020 src/data/regions/2020-births-south.json T1
# 옛 5년 주기 표는 KOSIS_PRDSE=F, 부·군·면 3단 코드 표는 KOSIS_LEVEL=5, 합계 항목이 없으면 KOSIS_SUM=1,
# 코드가 순번이라 시·구 계층 규칙이 안 맞는 표(1935·1955)는 KOSIS_NODISTRICT=1
KOSIS_API_KEY=... KOSIS_PRDSE=F KOSIS_LEVEL=5 KOSIS_NODISTRICT=1 node scripts/import-kosis.mjs DT_1IN3501 1935 src/data/regions/1935-kokusei.json T30
node scripts/annotate-now.mjs src/data/regions/1935-kokusei.json

# 호구총수·국세조사처럼 표로 정리한 CSV (province,name,weight,now)
node scripts/import-csv.mjs my-1789.csv src/data/regions/1789-hogu-chongsu.json
```

CSV 양식은 `scripts/templates/regions.csv` 에 있다. `now` 열은 옛 군현 하나당 대표 지역 한 줄만 적는다 (양주목 → 양주·의정부·남양주).

## 출처 배지

각 항목 옆의 작은 pill 배지를 누르면 근거 자료 목록이 열린다.

| 배지 | 뜻 |
|---|---|
| 통계 | 통계청·대법원·UN 등 실측 통계 |
| 추정 | 원전 기록이나 모델 생명표에 기초한 학술 추정 |
| 창작 | 기록이 없어 이 사이트가 만든 값 (문자 이전 시대 이름 등) |

출처 목록은 `src/data/sources.ts` 에 있다.

## 구조

```
src/
  engine/
    rng.ts          시드 난수
    eras.ts         시대 구간 10개, 연도 표기
    demography.ts   인구·출생률·합계출산율 곡선, 출생아 가중 추첨
    generate.ts     생성 파이프라인
    types.ts
  data/
    sources.ts      출처 레지스트리
    tables.ts       국가·지역, 계급, 직업, 주식
    names.ts        이름
    mortality.ts    사망확률 파라미터, 역사 사건, 사망 원인
  ui/               시작·생년 공개(YearReveal)·상세 카드, 출처 pill, 출처 모달
```

## 알려진 한계

- 전근대 수치는 전부 추정이며, 지역·계급 격차는 단순 배수로만 반영했다.
- 근현대 인기 이름 목록은 상위 20개 근사치다.
- 발해·낙랑 등 한반도 일부만 걸친 정치체는 한반도 안의 영역만 다룬다.
